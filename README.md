# Amazon Fire TV Hackathon Web App — 10-Foot UI Experience

A high-performance, TV-optimized single-page web application built for the Amazon Fire TV and Prime Video ecosystem. This project delivers a native living room streaming experience, complete with directional remote-control navigation, multi-channel live playback, interactive X-Ray trivia, and comprehensive system settings.

## 🚀 Key Features

* **10-Foot UI Architecture:** Designed specifically for living room viewing distances with large, high-contrast typography, cinematic background gradients, and smooth glowing focus states.
* **Fire TV Remote Navigation:** Fully implemented keydown event listeners supporting D-Pad directional arrow navigation and the **Enter** selector key.
* **Multi-Channel Live Stream Player:** Features an authentic Prime Video header, live status badge, description panel, and a remote-friendly channel switcher to toggle between different video feeds.
* **Interactive X-Ray Pop-Quiz Trivia:** Engaging multi-question trivia module testing AWS and Fire TV development knowledge with real-time score tracking and feedback.
* **Advanced System Preferences (Settings):** Fully interactive configuration menu allowing users to toggle user profiles (*Indira (Owner)*, *Developer Pro*, etc.), 4K/1080p streaming quality, audio languages (English, Telugu, Spanish), closed captions, parental controls, and network connections.

## 🛠️ Tech Stack

* **HTML5 / CSS3 / JavaScript:** Built using pure vanilla web technologies with a lightweight, zero-dependency single-page architecture for fast loading on embedded TV browsers.

## 🏃‍♂️ Running Locally

1. Clone or download the repository.
2. Open the **`index.html`** file in any modern web browser or Fire TV WebView container.
3. Use your keyboard's **Arrow Keys** to navigate between menu items and press **Enter** to select items and control media/settings.
